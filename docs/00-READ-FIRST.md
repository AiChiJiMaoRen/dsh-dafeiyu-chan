# dsh-dafeiyu · 接手入口（新会话 / 新 AI 先读这一份）

> 本插件是 DeepSeek Harness 里的陪伴看板娘「大肥鱼」（鲸鱼娘）。它有**两条各自独立的开发线**，接手前先在这里搞清。
> （注意：文件名用纯英文 ASCII，是为了避免中文文件名在部分工具/GPT 里无法读取。）

## 一、两条线（分开开发、互不干扰）

| 线 | 是什么 | 现在在干嘛（当前焦点） | 状态文档 |
|---|---|---|---|
| 🗨️ **会话线 Bubble Chat** | 不再使用聊天面板；用户直接使用 dsh 外层主输入框，大肥鱼会话统一在桌宠气泡中显示；主输入框与工作 AI 的正常聊天也会同步触发桌宠 | **已实现、待页面验收**：气泡先显示伪思维摘要，再显示正常回复；表情包暂停。工作 AI 联动是保留设定，不要当作 bug 移除 | `01-Dialog.md` + `03-Dialog-Contract.md` |
| 🐋 **桌宠线 DeskPet** | 可选显示在主输入框或左侧栏 dock 输入框**上方**的动态角色，用你的绿幕视频 **canvas 逐帧**演出，也是 Bubble Chat 的载体 | **单 canvas 播放器 + 事件总线/演出优先级已落地**；设置可切换两种锚点并立即生效 | `04-DeskPet.md` + `05-DeskPet-Import-Workflow.md` |

**哪条线都是别的会话可能接着开发的**：做气泡会话开线①，做桌宠动画开线②，先读对应状态文档的"现状 + 下一步 + 红线"，别把两条线混着改。

## 二、马上判断"现在要干什么"

1. **继续做桌宠 / 气泡会话** → 读 `04-DeskPet.md`，重点看"当前焦点"、"下一步"和"红线"。
2. **迁移会话 UI** → 读 `01-Dialog.md` + `03-Dialog-Contract.md`。旧的 `02-Dialog-UI.md` 只保留作废弃面板的历史交接，不应按它实现。
3. **新素材 / 新对话集** → 桌宠素材提示词 `h3-life-prompts.md`；桌宠批量导入按 `05-DeskPet-Import-Workflow.md` 执行。

## 三、AI 维护文档的约定（重要，每个会话都遵守）

为了让下个接手者永远"一读就懂"，**每个会话结束时必须**：

1. **更新状态文档**：把对应文件（`01-Dialog.md` 或 `04-DeskPet.md`）里的「当前焦点 / 下一步 / 已做到哪」改成实况，并更新文件头部 `状态时间`。
2. **别让它过期漂移**：发现代码和文档不一致，**先改文档**（文档是单一事实源），再动代码；改完代码务必同步文档。
3. **红线 / 已废弃** 一定写进去，防止下个会话回退。
4. 临时探针、调试角标、过渡方案：**要么留说明、要么清掉**，别让后来的会话蒙圈。

> 违反维护约定的后果：下个会话无法判断"现在在干嘛"，会重复踩坑、反复返工。这是**交接的一部分**，不是"有空再说"。
